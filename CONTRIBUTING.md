# Contributing

- **A command or limit changed:** open a pull request with the CLI version you checked (`eos --version`).
- **A new failure mode:** add a row to `docs/troubleshooting.md` with the symptom, the cause and the fix.
- **A new preflight check:** add it to `scripts/preflight.py` with a test in `tests/`.
- Describe behavior, not outcomes. No numbers you cannot source. No compliance claims.
- Never include tokens, keys, connection strings or customer data.
